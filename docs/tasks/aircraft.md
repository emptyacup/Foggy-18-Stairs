# 任务卡：aircraft（飞船、飞车、飞艇）

**文件**：`src/world/aircraft.js`（可建 `src/world/aircraft/`）
**预算**：250k 三角面 / 10 光场灯 / 300 光晕

## 目标
让天空"活"起来、有尺度感：远处悬停着巨大的母舰，塔楼之间流淌着飞车灯河，一艘广告飞艇慢慢飘过江面，一架警用飞行器低空悬停在大阶梯上空，探照灯扫过人群。

## 内容
1. **悬停母舰**（`L.MEGA.carrier`）：600+ m 长，轮廓要有设计感（楔形/分段舰体、舰桥、引擎舱、天线、机库口）。表面用实例化的面板/凸起做细节（greeble），腹部是成千上万的小灯点阵，舰底有几道垂向城市的光束。缓慢上下浮动（只由 t 决定），航行灯闪烁。被雨云半遮挡。
2. **飞车航道**：在 `L.MEGA.skyLanes` 各高度沿样条航线流动的飞车（实例化小机体 + 白色前灯 / 红色尾灯），远处只是光点串成的"灯河"，近处能看出造型。有一条航线从江对岸飞向镜头、从坡顶上空掠过（y ≈ 60–90），制造视差。
3. **广告飞艇**：100–150 m 长的软式飞艇，在江面上空 120–180 m 缓慢横移；两侧挂巨屏（`ctx.tex.canvas()` 画中文广告 + 动画），腹部一盏向下的探照灯。致敬《银翼杀手》。
4. **警用飞行器（Spinner）**：1–2 架，悬停在大阶梯上空（z ≈ -40..-70，y ≈ 60–75），红蓝警灯交替闪烁，一道探照灯光锥扫过阶梯和人群（可以挂一个移动的 `ctx.lights.add` 照亮地面）。
5. 移动的发光体请自己写 shader 做眩光/光晕（核心 `ctx.halos` 只支持静态位置）；参考 `src/world/lib/traffic-cars.js` 里车灯眩光的写法。
6. 全部动画只由时间 t 决定（截图 dt=0）。

## 自检
- `hero` 必须能看到：母舰（远、大）、至少一条飞车灯河、警用飞行器及其光锥。
- `node tools/shot.mjs --only environment,terrain,buildingsW,buildingsE,monorail,megacity,aircraft,weather --cams hero,terrace,vista --out shots/aircraft/vN`，多试几个 `--t`。
