# 任务卡：街面模块 v2 适配（shops / signs / props / wires / traffic / characters）

布局已从 7 m 窄巷改为 v2「山城观景大阶梯」，详见 `docs/DESIGN.md` §0 §4 §8 与 `src/world/layout.js`。
这些模块是按旧布局写的，代码里有不少**写死的坐标**（旧阶梯 `x=±3.5`、旧 z 区间 `-6..-66`、旧滨江路 `z=-66..-84 / y=4`、旧机位），需要逐一改成从 `layout` 读取。

## 共同原则（v2 新增）
- **视线通廊**：主镜头 `hero` 从坡顶俯瞰远处巨构城。阶梯正上方 `|x| < 6`、高于坡面 3 m 的空间**不放任何东西**（电线、灯串、晾衣、招牌都不行）。
- **街面热闹集中在两侧**：阶梯 20 m 宽，`|x| ∈ [5, 10]` 是两侧的"街"，中间 `|x| < 3` 保持畅通（人可以走）。
- **平台是广场**：较宽的平台（6 m）可以有外摆、摊位、人群，但同样避开中线视线。
- 坡底观景平台（`L.PLAZA`，y=10）、滨江路（`L.ROAD`，y=0）、江堤（z=-150）都换了位置。

## 分工
### A：shops + signs
- shops：底商立面在 `x = ±10`（facades 服务），地块进深 20 m；`S1/S2` 在坡顶广场背后；山坡街区 HW/HE 的底层不在 shops 范围（太远）。
- signs：竖招牌只在 `|x| ∈ [8.5, 10]` 挑出（不进入通廊）；楼顶大字面向南、放在不挡远景的地块（近处低楼的屋顶上较好）；牌坊已由主控改好，保留。
- 读取 `facade.fixtures` 避开楼体挑出物（buildings 已发布）。

### B：props + wires
- props：沿两侧 `|x| ∈ [5, 9.5]` 布置；坡顶广场、坡底观景平台（看江的长椅、望远镜）、滨江路人行道重新定位；删除旧坐标写死的内容。
- wires：电线、灯串**只沿两侧立面走**，或在 `|x| > 6` 的范围内斜拉；不横跨阶梯中线上空。可以在阶梯两侧做"电线杆 + 沿街架空线"。电线杆位置避开 terrain 新路灯（平台两侧 `x = ±8.6`）。

### C：traffic + characters
- traffic：滨江路 `y=0`，`z ∈ [-126, -146]`，长度 `x ∈ [-400, 400]`；斑马线在 `x ≈ -30`（红绿灯随之挪过去）；坡顶街道 `z ∈ [2, 9]`，`y = 40`。
- characters：阶梯上的人分布在两侧与平台；坡底观景平台栏杆边有看江的人（背对镜头，剪影对着巨构城最好看）；滨江路人行道与斑马线随 traffic 调整。

## 自检
- 每个模块 `node tools/check.mjs <module>` 必须 RESULT: OK（包括越界检查 0 个）。
- 截图：`node tools/shot.mjs --cams hero,mid,up,terrace,road --out shots/<module>-v2/vN`，Read 查看。`hero` 里阶梯中间必须能看穿到江对岸。
