# 任务卡：wires（头顶层）

**文件**：`src/world/wires.js`
**预算**：90k 三角面 / 0 光场灯 / 40 光晕（灯串用 `ctx.make` 的小发光体 + 少量光晕）

## 目标
山城老街头顶是**乱的**：电线、网线、电缆束在楼与楼之间横跨梯坎，晾衣绳挂着衣服，节日灯串，偶尔一根电线杆上挂着变压器和一团盘线。
现在头顶是空的。做完以后，从 `hero` / `mid` 抬头看，天空应该被切成碎片，电线在霓虹的逆光里成为剪影。

## 内容
- 读 `facades` 服务（兜底用 `L.LOTS`）。在东西两侧立面之间、高度 4.5 m 到楼顶之间随机连线：
  - 横跨梯坎的电线（`ctx.wires.add`，sag 0.3–1.2，r 0.008–0.02），成束出现（3–8 根同一起止点附近）。
  - 沿立面水平走的电缆、在墙角向下汇集的线束。
  - 墙上的接线盒、电表箱（小盒子）、瓷瓶支架。
- 2–3 根水泥电线杆（梯坎平台边、上半城街），杆顶横担 + 变压器 + 大量引线。
- 晾衣绳：阳台之间 / 横跨梯坎的低处（≥ 3.2 m），挂衣服（小平面，`mat.std` 彩色，`side: DoubleSide`）。
- 灯串：1–2 条横跨梯坎的暖色小灯泡串（小球 `mat.neon` + 少量光晕），灯泡沿悬链线分布。
- 注意：`ctx.wires` 是核心提供的悬链线合并器，构建结束后由 main 统一合批，你只需 `add`。

## 自检重点
- `hero` 抬头（自定义机位 pitch 0.3）和 `up` 机位：电线是否形成有层次的剪影，而不是均匀网格？
- 密度：近处密、远处疏；要有几处"特别乱"的视觉焦点。
