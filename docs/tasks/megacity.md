# 任务卡：megacity（江对岸巨构城 + 巨型屏幕）—— v2 最重要的模块

**文件**：`src/world/megacity.js`（可建 `src/world/megacity/`）；**同时接管 `src/world/environment.js`**（可重构其中的天际线，但保留江面、跨江大桥、倒影光带的功能）
**预算**：megacity 400k 三角面 / 8 光场灯 / 400 光晕；environment 300k / 12 / 500

## 目标
主镜头 `hero` 从坡顶往北看，越过大阶梯与江面，**整片天空被巨构城占据**：300–820 m 的塔楼、塔身上几十到上百米高的发光屏幕在播放人像、塔顶光柱刺进雨云、探照灯在云底扫动。要有《银翼杀手 2049》洛杉矶远景那种压迫感。

## 内容
1. **巨构塔楼**（`L.MEGA.zNear..zFar`）：40–80 栋，近处矮、远处高、中轴两侧最密。造型不要方盒子：退台、收分、腰部外挑平台、斜切顶、尖塔、天线束、塔与塔之间的空中连廊。
   - 立面用 shader 画窗（参考 `environment.js` 里的程序化窗户），加竖向/横向 LED 灯带、边缘霓虹线。
   - 远处塔楼被雨雾吞掉下半截（高度雾），只露出发光的上半部。
2. **中央地标「雾都塔」** `L.MEGA.hero`：820 m，层层光环、塔冠发光、顶部一道光柱直冲云层（加法混合体积光柱）。
3. **巨型屏幕**（重点，≥ 8 块，朝南面向镜头，40–150 m 高）：内容用 `ctx.tex.canvas()` 程序化绘制 + shader 动画，**不允许外部图片**。至少包括：
   - **川剧变脸**：脸谱每隔几秒"变"一次（红/黑/金/蓝脸谱，canvas 画对称脸谱纹样）。重庆/四川元素，必须有。
   - **人像**：风格化女性侧脸/正脸（矢量插画风：脸型轮廓、眼睛会眨、头发几缕高光、霓虹描边），可以做成 2–3 帧动画。
   - **眼睛特写**、虚构品牌广告（中文大字 + 英文小字）、滚动的竖排中文字幕、二维码风格的方块、故障（glitch）切换。
   - 屏幕 shader：像素点阵网格、扫描线、偶发色差撕裂、亮度足以产生泛光（intensity 2–4）；屏幕在雾里要有光晕。
4. **探照灯**：4–8 束，从塔顶射向云底，按时间 t 缓慢扫动（加法混合光锥，雾里可见）。
5. **云底被照亮**：屏幕与光柱下方的云层有彩色反光（可以在塔顶上方放大面积低强度光晕，或给 environment 的天空加局部染色）。
6. 江面倒影：让 environment 的倒影光带也反映巨屏颜色（拉长的彩色光柱）。

## 自检
- `hero`、`terrace`、`vista` 三个机位都要看。`hero` 里巨构应在两侧楼顶上方占据天空的大部分，而不是一条缝。
- 机位：`node tools/shot.mjs --only environment,terrain,buildingsW,buildingsE,monorail,megacity,weather --cams hero,terrace,vista --out shots/megacity/vN`
- 远景要"读得出来"：轮廓清晰、层次（近塔亮、远塔被雾吃掉）。
