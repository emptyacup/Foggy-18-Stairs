# 任务卡：shops（底商店面）—— 画面最重要的模块

**文件**：`src/world/shops.js`（可建 `src/world/shops/`）
**预算**：260k 三角面 / 120 光场灯 / 120 光晕
**发布服务**：`shopfronts`

## 目标
梯坎两侧 W1–W5、E1–E5 的底商层（`podiumTop - 1.0` 以下），加上上半城街南侧 S 街区、滨江路北侧 N 街区的底层。
现在这些位置是一面暗灰色的基座墙。做完以后，从 `hero` 往下看应该是**两排亮着灯、挤满东西的小店**，暖光洒在湿台阶上。

## 内容
- 把每个立面切成 2.5–4.5 m 的开间，每间一家店。店的类型（加权随机）：
  火锅/小面馆（暖橙，蒸汽，圆桌红凳）、小卖部（荧光白，货架饮料）、茶馆/麻将馆（暖黄，绿桌）、
  理发店（青白 + 旋转灯柱）、药房（绿十字）、五金/杂货（货物堆到门口）、关门的店（卷帘门 + 一点漏光）、空铺（黑、贴着招租纸）。
- 每间店：
  - **室内**：店面后退 0.3–1.2 m 形成门洞；室内用"假室内"做纵深：后墙用 `emissiveMap`（canvas 画货架/菜单/人影），侧墙和顶棚受光。
  - **门框、门槛、错层台阶**：地坪按 `L.heightAt(front, z)` 逐间确定，比梯坎高时加 1–3 级小台阶。
  - **雨棚**：彩色塑料或铁皮，伸出 0.8–1.6 m，带下垂的边、雨水滴线（可选）。雨棚下面是干的（材质 `wet` 低）。
  - **门口**：货架、冰柜（发光）、泡沫箱、价目牌、门帘（塑料条）。
  - **光**：每间亮着的店 1 个 `ctx.lights.add`（暖或冷），放在门口外 0.5 m、高 2.2 m，半径 5–8 m。这就是街面的主光源。
- 关门的店 20%，空铺 10%，节奏要错落。
- 发布 `ctx.provide('shopfronts', [...])`：`{facadeId, u0, u1, floorY, top, kind, open}`。

## 自检重点（截图看）
- `hero`、`mid`、`up` 三个机位下，梯坎两侧下半部分是否"满"、亮、有纵深？
- 店内灯光是否把门口的湿台阶照亮、在 SSR 里有倒影？
- 有没有在梯坎中线 `|x|<1.5` 放障碍物？
