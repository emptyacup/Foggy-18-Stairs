# 任务卡：traffic + characters（车与人）

一个 agent 负责两个模块。

## traffic —— `src/world/traffic.js`
**预算**：160k 三角面 / 60 光场灯 / 160 光晕

- 滨江路（`L.ROAD`）双向 4 车道，上半城街（`L.UPPER`）单车道。
- 车型：出租车（重庆出租车是黄色系，可虚构配色）、私家车、面包车、公交车（发光车窗）、摩托车。用几种低多边形造型 + 实例化或少量 Group。
- 车灯：前大灯（白，`mat.neon` + 移动的 `ctx.lights.add`，地面上有倒影最重要）、尾灯（红）。光场灯数量有限：只给离 `hero`/`road` 镜头近的几辆车挂动态光。
- 运动：位置只由 `t` 计算（周期循环、车距固定、在红绿灯前排队可选）。
- 红绿灯：梯坎底部斑马线两侧，按 `t` 切换，灯头有发光 + 光晕。
- 滨江路两侧可加隔离栏。

## characters —— `src/world/characters.js`
**预算**：140k 三角面 / 0 光场灯 / 0 光晕

- 低多边形人：头、躯干、四肢分段，比例对，有衣服颜色差异。**大部分人打伞**（伞是雨夜的灵魂：透明感塑料伞、红伞、黑伞）。
- 行为：
  - 沿梯坎上下走（按 `L.heightAt` 落脚，按 `t` 走循环路线，四肢简单摆动）。
  - 坐在火锅桌边、站在店门口、蹲在台阶上抽烟。
  - 1–2 个"棒棒"：挑扁担的搬运工。
  - 滨江路人行道上的行人、江边看夜景的人。
- 数量：30–60 人。远处的人可以更简。用 `ctx.use('walkways')` 避开道具。

## 自检重点
- `hero`：梯坎上有 3–6 个人，大小比例正确，伞的剪影清楚。
- `road`、自定义滨江路机位：车灯在湿路面上拉出长倒影。
