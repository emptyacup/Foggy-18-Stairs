# 任务卡：buildings（楼体升级）

**文件**：`src/world/buildingsW.js`、`src/world/buildingsE.js`、`src/world/lib/tower.js`、`src/world/lib/side.js`（你独占这四个文件）
**预算**：各 450k 三角面 / 各 40 光场灯 / 各 60 光晕
**注意**：`monorail.js` 也调用 `buildTower(ctx, spec)`，函数签名和返回的立面描述字段必须保持兼容（可以加字段）。

## 目标
现在的楼是"贴了窗户贴图的光滑盒子"，像草模。要变成**重庆老居民楼**：粗糙、加建、凹凸、层层叠叠。

## 内容
- **立面要有深度**：窗洞内凹（窗框 + 玻璃退进 0.15–0.3 m）、窗台、窗楣、层间腰线挑出。可以把立面拆成"每层一条带"的几何，而不是一整块贴图盒子。窗户亮灯继续用发光贴图或发光平面。
- **体块变化**：
  - 上部楼层整体悬挑（越往上越宽 0.3–1 m），或局部凸窗/凸阳台。
  - 楼顶加建：铁皮房、彩钢瓦屋顶、违章搭建的小阁楼、楼顶菜园、晾衣架。
  - 相邻楼之间留 0.3–1 m 的窄缝（缝里黑且深），或者用天桥/连廊连起来。
  - 少数地块做成吊脚楼（底部柱子 + 上部木/砖结构），尤其坡度大的位置。
- **立面杂物**：防盗网阳台（已有，可增强：内部塞满杂物、植物）、空调外机（有些带滴水痕）、热水器、排风扇、落水管、挂着的腊肉/衣服、墙上的小广告（"疏通下水道"之类的喷漆字，用 canvas 画）。
- **材质**：老瓷砖、水泥砂浆、红砖露出、霉斑与雨痕（贴图里画）。不同楼之间色差明显。
- **侧面/背面**：至少从 `overview` 看不出是复制粘贴的。
- 窗口溢光的光场灯保持（给梯坎染色）。

## 自检重点
- `hero`、`mid`、`up`：两侧墙面是否有明显的凹凸与阴影层次？轮廓线（天际）是否破碎有趣？
- `overview`：街区看起来是"长出来的"而不是"排出来的"？
