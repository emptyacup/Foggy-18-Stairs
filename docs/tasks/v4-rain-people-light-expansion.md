# v4：雨水积水 / 人物细节 / 提亮与白天 / 扩大可活动范围

用户反馈：雨水与水潭细节不够、周边人物太粗糙、整体略暗（白天不够通透）、可活动场景太小。
已确认方案：夜景提亮 + 白天改通透；人物"风格化但有细节"；扩展方向 = 两侧山坡巷道、滨江路沿江延伸、坡顶后方新街区。

## 改动

- **光照**（`core/palette.js` `core/sky.js` `core/ctx.js` `main.js`）：夜景 hemi 2.4→3.3、曝光 1.08→1.24；白天雾密度 0.004→0.0016、远景巨构城空气透视消光 ×0.3（`megaFog`，sky.setDaylight 原位缩放 `uFogK`）、白天雨势 0.55（`?rain=` 优先）。新增 `shared.uSkyTop/uSkyHor`。
- **积水反射**（`core/post.js` `core/mat.js`）：SSR 未命中时沿反射方向投到"无穷远"取屏幕色（对岸巨构城/天空），再退到天空渐变；原来退回暗雾色导致积水发黑。积水边缘去掉最高频噪声、加一圈半干湿痕 `puddleDamp`；涟漪改为大小两层、幅度加大，只在积水内计算。
- **人物**（`lib/characters-rig.js` `characters.js`）：收窄肩线、躯干收腰、细手臂与袖口；贴合胸口曲面的翻领 + 内搭；新发型（波波头/马尾/发髻/刘海）、长风衣下摆、裙子、雨衣、背包、围巾、口罩、眼镜、发光目镜；肤色提亮。可选部件按"用到的人"紧凑分配实例（`makeRig(ctx, n, need)`），人数 59→约 95 而三角面仅 185k（预算 140k→200k）。
- **扩展区**（新模块 `world/districts.js`，布局/高程在 `layout.DISTRICTS` + `districtHeightAt`，walkHeightAt 优先查询）：
  - 两侧山坡巷：楼群缝隙 L1/L2/L3 三条横巷 + |x|≈102–106 后山梯道连成环；补楼、素墙贴窗面、顺坡矮墙。`terrain` 山体台地外缘收到梯道内侧；`exploration` 梯巷外侧路沿/扶手在横巷口（`mz0/mz1`）断开。
  - 坡顶后方：后街南墙正中断开 → "梯后老街"牌坊、正街、黄葛树小广场 + 大排档、横街灯笼、30 级梯坎、坡上巷，约 22 栋楼带假室内店面。
  - 滨江：南侧骑楼街（|x| 62–200）+ 江边树池长凳路灯；x≈-105 跳板 + 趸船候船室 + 小渡轮（`terrain` 江边栏杆与防落水碰撞在跳板处断开）。
- `weather` 雨水高程图扩到 x±205、z -170..116。`index.html` 探索路线提示新增三条。`tools/test-exploration.mjs` 新增 5 条往返路线。

## 验证

- `node tools/check.mjs` 全量 RESULT: OK（约 1.65M 三角面，districts 370k / 520k 预算，lights 70）。
- `node tools/test-exploration.mjs`：10 条路线往返 20 PASS + 围挡/护栏断言 OK；`test-lighting.mjs` OK。
- `tools/bench.mjs` 1080p 真实循环：hero 75 fps、terrace 125 fps、mid 86 fps（GTX 1660 Ti）。
- 截图：`shots/review/`（n*/d* 光照与积水、ch*/face* 人物、dist*/v4* 扩展区）。

## 已知限制

- 白天仍是阴雨天（无晴天/太阳阴影）；对岸巨构城的部分填充楼在白天仍呈夜间亮窗。
- （v4.1 已部分解决：31 间店可进入，其余仍为假室内）扩展区行人走后山梯道时没有台阶步态。
- 山坡楼群行间窄缝仍可走进，台地视觉高度与可走高度略有差异（v3 前就存在）。

## v4.1：可进入店铺 / 假室内细节 / 扶手碰撞

- **扶手碰撞**：主阶梯两条分道扶手（x=±3.4，`terrain.js`）与梯后老街梯坎扶手（`districts.js`）按约 1 m 一段登记碰撞（顶面随台阶）；平台段照常可横穿。
- **可进入店铺**：新库 `world/lib/rooms.js`（`buildRoom`：地面/墙/门洞/天花灯管/按店种布置的家具与碰撞，7 种店）。`lib/tower.js` 新增 `spec.podiumHoles` 在基座上挖洞。
  - 主阶梯两侧：`lib/side.js` 的 `LOT_ROOMS` 在平台段选 5 间（E2 火锅、E3 理发、W3 茶馆、W4 面馆、E4 小卖部），`shops.js` 开间边界对齐并搭房间（对齐后剩下 < 1.6 m 的窄条只留基座墙）。
  - 梯后老街 18 间、滨江骑楼 6 间、山坡巷 2 间（`districts.js` 的 `rooms` 字段）。后街南侧矮墙在有新街区时不再建造（被临街楼取代，否则挡住店门）。
- **假室内**（`shops/paint.js`）：所有店后墙叠加生活细节（海报、挂历/挂钟、壁挂电视、线槽插座、空调、墙脚污渍）与光影层次；人影加一道室内灯轮廓光；面馆加调料架与碗摞。
- 验证：全量 check OK（约 1.69M 三角面）；`test-exploration.mjs` 13 条路线往返 26 PASS（含 3 条进店路线）+ 扶手横穿断言；`test-lighting` OK。
- 性能：本轮测量时 GPU 降频（76 °C、1200 MHz），对照视角 terrace 也从 14 ms 变 19.5 ms；同状态下有/无 districts 的 hero 帧时差异在噪声内（28–35 ms vs 31 ms）。需在 GPU 正常状态下复测。
