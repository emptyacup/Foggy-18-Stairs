# 任务卡：props（街面道具）

**文件**：`src/world/props.js`（可建 `src/world/props/`）
**预算**：220k 三角面 / 40 光场灯 / 60 光晕
**发布服务**：`walkways`（道具占用区）

## 目标
让街面"有人生活"。现在台阶、平台、上半城街、滨江路人行道、江边广场都是空的。

## 内容（每类都要做出可辨认的轮廓，不要只是盒子）
- **火锅外摆**：平台上的矮圆桌 + 红/蓝塑料凳（凳子要有四条腿和凳面的形状），桌上铜锅冒蒸汽（加法混合的蒸汽团，随时间缓慢上升、可用 shader 或几片 billboard）。
- **电瓶车 / 摩托车**：停在平台边、人行道上，有座垫、后视镜、雨披；个别车的尾灯亮着。
- **杂物**：蓝色塑料筐、泡沫箱、煤气罐、垃圾桶（绿色）、扫帚、纸箱堆（被雨打湿发暗）。
- **盆栽**：泡沫箱里种的葱、大盆绿植、三角梅从墙头垂下。
- **伞**：撑开放在地上的伞、店门口的大遮阳伞（收起或撑开）。
- **棒棒**：靠墙放的扁担和绳子。
- **积水边**：被雨水冲下来的落叶、井盖、小水沟上的铁箅子。
- **江边广场**：长椅、栏杆边的路牌、观景望远镜、一个关了的报刊亭（可亮灯）。
- 用 `InstancedMesh` 做大量重复物（凳子、筐）。
- 发布 `walkways`：所有占地 ≥ 0.5 m² 的道具占用矩形。

## 规则
- 梯坎中线 `|x| < 1.5` 不放东西。台阶上的道具要贴合台阶高度（`L.heightAt`）。
- 若读到 `shopfronts`，在开着的店门口加对应的东西（火锅店门口放桌凳，小卖部门口放冰柜/箱子）。

## 自检重点
- `hero`、`mid`、`up`、`road` 机位：前景是否有能看出是什么的物件？会不会太整齐（像摆拍）？
