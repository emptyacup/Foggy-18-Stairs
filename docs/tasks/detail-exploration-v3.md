## 探索方法

1. 转身穿过牌坊，从中央楼间空档向后街走；茶馆在左、杂货店在右，门洞可以直接走入。
2. 坡顶向左右沿街走，到 x≈±31.5 的两条楼后梯巷，可以下到观景平台。
3. 坡底观景平台往左，找到滨江标识；经新下行梯与挡墙局部门洞，过斑马线到江边步道。
4. 左上角“阴雨白天 / 切换夜景”控制日夜，“探索路线”展开提示。预览 `http://127.0.0.1:5173/?day=1`。
